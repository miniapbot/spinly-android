# Spinly — Android

🎰 Telegram Mini App и Android-приложение для игры в рулетку.

## Возможности

- Европейская рулетка (37 чисел)
- Бусты **×2 / ×3 / ×5 / ×10** на случайные числа
- «Почти попал» — возврат **50%** ставки, если соседнее число на колесе
- Задания дня и **16 достижений**
- Топ-5 игроков за неделю
- Рефералы: **+500 монет** тебе, **+250 монет** другу за приглашение
